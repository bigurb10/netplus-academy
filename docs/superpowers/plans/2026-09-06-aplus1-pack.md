# A+ Core 1 Course Pack Plan (APlus Academy Core 1)

**Goal:** A complete `courses/aplus1/` pack in the FieldReady Academy format for CompTIA A+ Core 1 (220-1201): manifest, cheat sheet, 42 original lessons across 9 units with a deeper explanation each, five original questions per lesson (about 210), generators for computable topics, course page, and catalog card.

**Status:** Plan written 2026-09-06 against the official CompTIA 220-1201 objectives (version 2.0). Cheat sheet written.

## Exam facts (from the official objectives)

- Up to 90 questions, 90 minutes, multiple choice and performance-based. Passing score 675 on a 100 to 900 scale. Recommended experience 12 months in IT support. The course bar is 85%.
- Domains: Mobile Devices 13%; Networking 23%; Hardware 25%; Virtualization and Cloud Computing 11%; Hardware and Network Troubleshooting 28%.
- The troubleshooting methodology is documented as a best practice but is not itself tested; it is taught here as the frame for every troubleshooting lesson.

## What the objectives name (every lesson maps to these)

- **1.0 Mobile Devices**: laptop hardware replacement (battery, keyboard, RAM, HDD/SSD, wireless cards, biometrics, NFC, antenna placement, camera, microphone); connections (USB-C, microUSB, miniUSB, Lightning, NFC, Bluetooth, tethering/hotspot) and accessories (stylus, headsets, speakers, webcam, docking station, port replicator, trackpad); network connectivity (3G/4G/5G, hotspot, Wi-Fi, SIM/eSIM, Bluetooth pairing steps, GPS and cellular location); MDM (corporate versus BYOD, policy enforcement, corporate applications); synchronization (data caps, calendar, contacts, mail, cloud storage).
- **2.0 Networking**: ports 20/21, 22, 23, 25, 53, 67/68, 80, 110, 137 to 139, 143, 389, 443, 445, 3389; TCP versus UDP; wireless frequencies 2.4, 5, 6 GHz, channels and widths and regulations, Bluetooth, 802.11 standards, NFC, RFID; server roles (DNS, DHCP, fileshare, print, mail, syslog, web, AAA, database, NTP), appliances (spam gateway, UTM, load balancer, proxy), SCADA, IoT; DNS records A, AAAA, CNAME, MX, TXT with DKIM, SPF, DMARC; DHCP leases, reservations, scope, exclusions; VLAN, VPN; hardware (routers, managed and unmanaged switches, access points, patch panel, firewall, PoE injectors, switches, and standards, cable modem, DSL, ONT, NIC and MAC); SOHO networks and IP addressing (IPv4 private and public, IPv6, APIPA, static, dynamic, mask, gateway); connection types (satellite, fiber, cable, DSL, cellular, WISP) and network types (LAN, WAN, PAN, MAN, SAN, WLAN); tools (crimper, stripper, Wi-Fi analyzer, toner probe, punchdown tool, cable tester, loopback plug, network tap).
- **3.0 Hardware**: display types (LCD IPS, TN, VA; OLED; Mini-LED), touch screen and digitizer, inverter, attributes (pixel density, refresh rate, resolution, color gamut); cables (copper categories, T568A/B, coax, STP, direct burial, UTP, plenum, single-mode and multimode fiber; USB 2.0, 3.0, serial, Thunderbolt; HDMI, DisplayPort, DVI, VGA, USB-C; SATA, eSATA; adapters; connectors RJ11, RJ45, F-type, ST, SC, LC, punchdown block, microUSB, miniUSB, USB-C, Molex, Lightning, DB9); RAM (SODIMM, DIMM, DDR iterations, ECC, channels); storage (spindle speeds, 2.5 and 3.5 inch; SSD NVMe, SATA, PCIe, SAS; M.2, mSATA; RAID 0, 1, 5, 6, 10; flash drives, memory cards; optical); motherboards (ATX, microATX, ITX; PCI, PCIe, power connectors, SATA, eSATA, headers, M.2; AMD and Intel sockets, multisocket; BIOS/UEFI boot options, USB permissions, TPM, fan, Secure Boot, boot and BIOS passwords, temperature monitoring; virtualization support; TPM and HSM; x86/x64, ARM, core configurations; sound, video, capture, network cards; fans, heat sink, thermal paste and pads, liquid); power supplies (110 to 120 versus 220 to 240 VAC, 3.3, 5, 12 V outputs, 20+4 pin, redundant, modular, wattage, efficiency); printers (unboxing and location, PCL versus PostScript drivers, firmware, USB, Ethernet, wireless, printer share versus print server, duplex, orientation, tray, quality, authentication, badging, audit logs, secured prints, scan to email, SMB, cloud, ADF and flatbed); printer maintenance (laser: toner, maintenance kit, calibrate, clean; inkjet: cartridge, printhead, roller, feeder, cleaning, calibrating, jams; thermal: feed assembly, paper, heating element; impact: multipart paper, ribbon, printhead).
- **4.0 Virtualization and Cloud**: VM purposes (sandbox, test development, application virtualization for legacy and cross-platform), requirements (security, network, storage), VDI, containers, type 1 and type 2 hypervisors; cloud models (private, public, hybrid, community, IaaS, SaaS, PaaS); characteristics (shared versus dedicated, metered utilization with ingress and egress, elasticity, availability, file synchronization, multitenancy).
- **5.0 Troubleshooting**: boards, RAM, CPU, power symptoms (POST beeps, proprietary crash screens, blank screen, no power, sluggish, overheating, burning smell, random shutdown, application crashes, unusual noise, capacitor swelling, wrong date and time); drives and RAID (LED indicators, grinding, clicking, bootable device not found, data loss, RAID failure, S.M.A.R.T., extended read/write times, low IOPS, missing drives, array missing, audible alarms); video and display (input source, cabling, bulb, fuzzy, burn-in, dead pixels, flashing, color, audio, dim, projector shutdown, sizing, distortion); mobile (battery health, swollen battery, broken screen, charging, connectivity, liquid damage, overheating, digitizer, damaged ports, malware, cursor drift, cannot install apps, stylus, degraded performance); network (intermittent wireless, slow speeds, limited connectivity, jitter, VoIP quality, port flapping, latency, interference, authentication failures, intermittent internet); printers (lines, garbled print, jams, faded, not feeding, multipage misfeed, pending queue, speckling, double images, grinding, finishing, orientation, tray not recognized, connectivity, frozen queue).

## Naming

Course name **APlus Academy Core 1**, badge **A1**, id `aplus1`. Core 2 will be **APlus Academy Core 2**, badge **A2**, id `aplus2`. One course per exam, as agreed.

## Content rules

Original prose and original questions; no reference to any book, author, or page; the study guide epub in `E:\CERT GUIDES\COMPTIA A+` is for ideas only. Every lesson has a deeper explanation with an analogy, a diagram or table, worked examples, "how the exam asks it", and "what to memorize". Numbers (speeds, pins, volts, ports, distances) are stated consistently in the cheat sheet, lessons, deep dives, and generators.

## Units and lessons (42)

**U1 Mobile Devices (domain 1)**
- u1l1 Laptop hardware: replacing batteries, keyboards, RAM, storage, wireless cards, cameras, and biometrics
- u1l2 Mobile connections and accessories: USB-C, Lightning, NFC, Bluetooth, tethering, docks, port replicators, styluses
- u1l3 Mobile network connectivity: cellular generations, SIM and eSIM, Wi-Fi, hotspots, Bluetooth pairing, location services
- u1l4 MDM, BYOD, and synchronization: device configurations, policy enforcement, corporate apps, sync, data caps

**U2 Networking Fundamentals (domain 2)**
- u2l1 How data moves: MAC and IP, frames and packets, switches and routers, the layers in plain terms
- u2l2 TCP versus UDP and the port list
- u2l3 Wireless technologies: bands, channels, widths, 802.11 standards, Bluetooth, NFC, RFID
- u2l4 Network hardware: routers, switches, access points, patch panels, firewalls, PoE, modems, ONTs, NICs
- u2l5 Services of networked hosts: server roles, internet appliances, SCADA, IoT

**U3 Network Configuration (domain 2)**
- u3l1 IPv4 addressing: private and public ranges, masks, gateways, APIPA, static versus dynamic
- u3l2 IPv6 essentials and loopback: address format, link-local, global, dual stack
- u3l3 DNS records and email authentication: A, AAAA, CNAME, MX, TXT, SPF, DKIM, DMARC
- u3l4 DHCP, VLANs, and VPNs
- u3l5 SOHO network setup: router, wireless, addressing, and connection types (satellite, fiber, cable, DSL, cellular, WISP); network types (LAN, WAN, PAN, MAN, SAN, WLAN)
- u3l6 Networking tools: crimper, stripper, punchdown, tester, toner probe, loopback plug, Wi-Fi analyzer, tap

**U4 Cables, Connectors, and Displays (domain 3)**
- u4l1 Network cables: copper categories, T568A and T568B, shielding, plenum, direct burial, coax, fiber
- u4l2 Peripheral, video, and drive interfaces: USB generations, Thunderbolt, USB-C, Lightning, serial, HDMI, DisplayPort, DVI, VGA, SATA, eSATA, Molex, adapters
- u4l3 Displays: LCD types, OLED, Mini-LED, digitizers, inverters, resolution, density, refresh, gamut

**U5 Memory, Storage, Motherboards, and Power (domain 3)**
- u5l1 RAM: DIMM and SODIMM, DDR3 to DDR5, ECC, channels, virtual memory
- u5l2 Storage devices: HDDs, SATA and NVMe SSDs, M.2, mSATA, SAS, removable, optical
- u5l3 RAID 0, 1, 5, 6, and 10 with capacity math
- u5l4 Motherboards: form factors, slots, power connectors, headers, sockets, chipsets
- u5l5 BIOS and UEFI: boot options, Secure Boot, TPM, passwords, fans, virtualization support, HSM, CMOS
- u5l6 CPUs, expansion cards, and cooling
- u5l7 Power supplies: input voltage, rails, connectors, wattage, efficiency, modular, redundant

**U6 Printers (domain 3)**
- u6l1 Printer deployment and configuration: drivers, PCL versus PostScript, connectivity, sharing, settings, security, scanning
- u6l2 Laser printers: the seven-step imaging process, components, and maintenance
- u6l3 Inkjet, thermal, and impact printers: components and maintenance

**U7 Virtualization and Cloud (domain 4)**
- u7l1 Virtualization: purposes, hypervisor types, VDI, containers
- u7l2 Building a virtual machine: requirements, network modes, storage, snapshots, security
- u7l3 Cloud models: public, private, hybrid, community; IaaS, PaaS, SaaS
- u7l4 Cloud characteristics: shared versus dedicated, metering, elasticity, availability, file sync, multitenancy

**U8 Troubleshooting Hardware (domain 5)**
- u8l1 The troubleshooting method and the technician's toolkit (multimeter, PSU tester, POST card, loopback, known-good parts)
- u8l2 Motherboard, RAM, CPU, and power symptoms
- u8l3 Drive and RAID symptoms
- u8l4 Video, projector, and display symptoms
- u8l5 Mobile device symptoms
- u8l6 Worked hardware cases: from symptom to fix, five complete walkthroughs

**U9 Troubleshooting Networks and Printers (domain 5)**
- u9l1 Network symptoms: wireless, speed, limited connectivity, latency and jitter, port flapping, interference, authentication
- u9l2 Printer output problems: lines, faded, speckling, ghosting, garbled, fusing, color and orientation
- u9l3 Printer feed, queue, connectivity, and finishing problems

## Generators (`courses/aplus1/generators.js`)

- u2l2 ports: port to protocol, protocol to port, TCP or UDP, which secure port replaces which.
- u2l3 wireless: standard to band and speed, band to channel facts, Wi-Fi name to standard.
- u3l1 addressing: private or public, same subnet or via gateway, APIPA recognition, which address is the gateway candidate.
- u3l3 DNS records: which record for a given need; what a record type does; SPF/DKIM/DMARC roles.
- u4l1 cables: category to speed and bandwidth, run length, T568 pin order, fiber mode to distance.
- u4l2 interfaces: USB and Thunderbolt generation to speed, video connector traits, SATA generation to speed.
- u5l3 RAID: usable capacity and fault tolerance for n drives of size s in RAID 0, 1, 5, 6, 10; minimum drives.
- u9l2 printer symptoms: symptom to likely cause and first action.
