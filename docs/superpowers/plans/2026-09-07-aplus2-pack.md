# A+ Core 2 Course Pack Plan (APlus Academy Core 2)

**Goal:** A complete `courses/aplus2/` pack in the FieldReady Academy format for CompTIA A+ Core 2 (220-1202): manifest, cheat sheet, 41 original lessons across 9 units with a deeper explanation each, five original questions per lesson (205), generators for computable topics, course page, and catalog card, verified against every bullet of the official objectives.

**Status:** Plan written 2026-09-07 against the official 220-1202 objectives (reproduced in the study guide's second volume). Cheat sheet written.

## Exam facts

- Up to 90 questions, 90 minutes, multiple choice and performance-based. Passing 700 on a 100 to 900 scale. The course bar is 85%.
- Domains: Operating Systems 28%; Security 28%; Software Troubleshooting 23%; Operational Procedures 21%.

## Objectives (every lesson maps to these)

- **1.1** OS types (Windows, Linux, macOS, Chrome OS; iPadOS, iOS, Android), filesystems (NTFS, ReFS, FAT32, ext4, XFS, APFS, exFAT), vendor life cycle (EOL, update limitations), compatibility. **1.2** Boot methods, installation types, partitioning (GPT, MBR), drive format, upgrade considerations, feature updates, product life cycle. **1.3** Windows 10 and 11 editions, N versions, feature differences (domain versus workgroup, desktop styles, RDP, RAM limits, BitLocker, gpedit.msc), upgrade paths, hardware requirements (TPM, UEFI). **1.4** Task Manager tabs, MMC snap-ins by .msc name, additional tools by .exe name. **1.5** Command-line tools (navigation, network, disk, file, informational, OS management). **1.6** Control Panel applets, File Explorer options, Power Options, Settings categories. **1.7** Windows networking (domain versus workgroup, shares, mapped drives, firewall, client IP settings, VPN, wireless, wired, WWAN, proxy, public versus private, network paths, metered). **1.8** macOS (file types, App Store, uninstall, system folders, Apple ID and corporate restrictions, best practices, System Preferences, features, Disk Utility, FileVault, Terminal, Force Quit). **1.9** Linux (file, filesystem, administrative, package, network, informational commands; nano; config files; systemd, kernel, bootloader; root). **1.10** Application requirements, compatibility, distribution methods, impact considerations. **1.11** Cloud productivity tools (email, storage sync, collaboration, identity sync, licensing).
- **2.1** Physical security, physical access, logical security (least privilege, Zero Trust, ACLs, MFA methods, SAML, SSO, JIT, PAM, MDM, DLP, IAM, directory services). **2.2** Windows security settings (Defender, firewall, users and groups, login options, NTFS versus share permissions, attributes, inheritance, run as, UAC, BitLocker, BitLocker To Go, EFS, Active Directory tasks). **2.3** WPA2, WPA3, TKIP, AES; RADIUS, TACACS+, Kerberos, multifactor. **2.4** Malware types and tools. **2.5** Social engineering, threats, vulnerabilities. **2.6** Malware removal, seven steps. **2.7** Workstation hardening. **2.8** Mobile device security. **2.9** Data destruction and disposal. **2.10** SOHO router, wireless, and firewall settings. **2.11** Browser security.
- **3.1** Windows OS symptoms (BSOD, degraded performance, boot issues, frequent shutdowns, services not starting, applications crashing, low memory, USB controller resource warnings, instability, no OS found, slow profile load, time drift). **3.2** Mobile OS and application issues. **3.3** Mobile security issues (concerns and symptoms). **3.4** PC security symptoms and browser symptoms.
- **4.1** Ticketing, asset management, document types, knowledge base. **4.2** Change management. **4.3** Backup and recovery (full, incremental, differential, synthetic full; recovery; testing; rotation, GFS, 3-2-1). **4.4** Safety. **4.5** Environmental impacts and controls. **4.6** Incident response, licensing, regulated data, AUP, compliance, splash screens. **4.7** Communication and professionalism. **4.8** Scripting (file types, use cases, considerations). **4.9** Remote access (RDP, VPN, VNC, SSH, RMM, SPICE, WinRM, third-party tools, security). **4.10** AI basics.

## Generators (`courses/aplus2/generators.js`)

- u2l1 tools: task to tool, tool name to .msc or .exe, .msc to tool.
- u2l3 Windows commands: command to job, task to command, switch meaning.
- u3l2 Linux commands: command to job, task to command, chmod numeric permissions, config file to contents.
- u4l4 malware: description to type; tool to purpose.
- u5l1 permissions: effective permission from NTFS plus share (most restrictive), copy versus move inheritance rules.
- u5l8 malware removal: which step comes next, step number to action.
- u6l1 Windows symptoms: symptom to likely cause and first action.
- u7l3 backups: which sets to restore for incremental versus differential; storage math; 3-2-1 and GFS facts.
